# Nocturne Planet ポスターアトラスツール

縦向きのポスターを9枚ずつ、VRChatワールドの入口掲示用画像にまとめるツールです。

**[ポスターツールを開く](https://r-fallingstar.github.io/nocturne-planet-poster-atlas/)**

ブラウザで `index.html` を開いて利用できます。画像はブラウザ内で処理し、サーバーへ送信しません。インストール、アカウント、外部ライブラリは不要です。

## 使い方

1. 縦向き1448×2048pxのポスター画像を用意します。
2. 「複数画像をまとめて追加」で読み込みます。ファイル名の番号順に9枚ずつ並び、10枚目以降は次のページになります。
3. 並び順、余白／トリミング、空き枠の募集ポスターを調整します。
4. PNGまたはJPGを保存します。全ページをZIPでも保存できます。
5. 保存した画像をDropboxにアップロードし、共有リンクをツール下部で直リンクへ変換します。

出力は1ページ1446×2046px（3列×3行、1枠482×682px）です。読み込んだ画像や配置はブラウザを閉じると消えるため、作業後に書き出してください。

お問い合わせは **Nocturne Planet公式X（[@NoctuPla_VRC](https://x.com/NoctuPla_VRC)）** まで。

## GitHub Pages

リポジトリの **Settings → Pages → Deploy from a branch → main / (root)** で公開します。

公開内容は `index.html` と `.nojekyll`、この説明書だけです。静的HTMLとして動作し、ビルドは不要です。
